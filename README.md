# ✈️ Route AI

### AI-Powered Travel Planning Assistant

Route AI is an AI-powered travel planning application built with **Python, Streamlit, and Google Generative AI**. It helps users create personalized travel plans based on their destination, preferences, budget, duration, and travel requirements.

---

## 🌍 About Route AI

Planning a trip often requires researching destinations, transportation, accommodation, activities, food, budget, and other travel requirements.

**Route AI brings these planning tasks together in one simple and interactive application.**

Users provide their travel preferences, and Route AI uses Generative AI to create a personalized travel plan with useful recommendations and a structured itinerary.

---

## ✨ Features

* 🗺️ **Personalized Itineraries**
  Generate structured day-by-day travel plans based on user preferences.

* 💰 **Budget-Based Planning**
  Create travel recommendations according to the user's selected budget.

* 🏨 **Accommodation Suggestions**
  Get accommodation recommendations suitable for the planned trip.

* 🚗 **Transportation Planning**
  Receive transportation suggestions for travelling between destinations.

* 🍜 **Food Recommendations**
  Discover food and dining recommendations based on the destination.

* 🎯 **Activity & Attraction Recommendations**
  Get suggestions for popular attractions, activities, and experiences.

* 🎒 **Smart Packing List**
  Generate a useful packing checklist based on the trip.

* 📋 **Structured Travel Plan**
  Receive the generated information in an organized and easy-to-follow format.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Python 3.x
* pip
* Git

### 1. Clone the Repository

```bash
git clone https://github.com/sampadagedam66-debug/route-ai.git
```

### 2. Navigate to the Project

```bash
cd route-ai
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure the Environment

Create a `.env` file in the project directory and add the required Google Generative AI API configuration.

```env
GEMINI_API_KEY=your_api_key_here
```

### 6. Run the Application

```bash
streamlit run app.py
```

The Route AI application will open in your default web browser.
